# Tiệm hoa mĩ miều

Website giới thiệu mẫu hoa của tiệm hoa mĩ miều. Trang tĩnh gồm HTML, CSS và JS thuần, không cần build.

- `index.html`: bố cục trang, footer (địa chỉ, liên hệ, mạng xã hội)
- `styles.css`: giao diện và hiệu ứng liquid glass
- `script.js`: danh sách mẫu hoa (mảng `FLOWERS`), hiệu ứng nền (cành hoa, cánh hoa, lấp lánh)
- `assets/flowers/`: ảnh hoa đã cắt nền (.webp)

Chạy thử ở máy: `python -m http.server 5173` rồi mở http://localhost:5173
